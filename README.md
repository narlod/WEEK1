# Cybersecurity Projects - Epicode School
Progetti hands-on dalla certificazione **CyberSecurity Specialist** (Dicembre 2022 – Febbraio 2023, 12 settimane).
## 📋 Progetti
**1. Creazione_Analisi_ReteCalcolator**  Network design e subnetting — progettazione di infrastrutture di rete con analisi CIDR e ottimizzazione.
**2. Policy Ping_INetSim_WireShark**  Traffic monitoring e ICMP analysis — cattura e analisi del traffico di rete con Wireshark e simulazione di servizi.
**3. Simulazione_SeverHTTP_S_ServerDNS_IntercettazioneTraffico**  HTTP/DNS server simulation e traffic interception — analisi di protocolli applicativi e intercettazione del traffico per assessment.
**4. Servizi_HTTP_DNS_DHCP**  Network services configuration — setup e gestione di servizi critici (HTTP, DNS, DHCP) in ambienti lab.

**Skills Dimostrate:** Network Analysis, Penetration Testing, Packet Capture, Protocol Analysis, Network Services Configuration  **Tools:** Kali Linux, Wireshark, INetSim
